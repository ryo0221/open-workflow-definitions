# 自動車の外観デザインの定義

`vehicle-styling@1.0.0` は、自動車の外観を、性格と規則、硬い点のパッケージ、空気の筋書きから先に決め、3面の線図と比率で全体の形を固めてから、面・細部・色と材料・最終の絵と動画へ進める定義です。

**11工程・12成果物・16項目・25引用／網羅規則・23達成条件**。各工程に人が確かめる達成条件があります。AI の達成条件は、見出しと項目の抜け、引用と網羅に限ります。形の良し悪しは、進め方で決めた判断する人が決めます。

## セクションと工程

| セクション | 工程 | 主な成果物 |
|---|---|---|
| 企画 | 進め方 → 性格と規則 | 進め方、性格と規則 |
| 骨格 | 硬い点とパッケージ → 空気の筋書き | 硬い点とパッケージ、空気の筋書き |
| 形 | 3面の線図 → 比率 | 3面の線図、比率 |
| 面と細部 | 面 → 空力の簡易検査 → 細部 | 面、空力の簡易検査、細部 |
| 仕上げ | 色・材料・絵 → 判断の記録と完成 | 色と材料、最終の絵と動画、判断の記録 |

`after` は工程の**受け入れ順**です。格好良さに一番効くのは、パッケージ・線図・比率です。比率の承認の前に面の工程へ進みません。面や細部の工程で形の問題が見つかったら、面を直すのではなく線図（必要ならパッケージ）へ戻り、直した版で比率から先をやり直します。

## 考え方

この定義は、レーシングカーの設計者の自伝から要約した次の考え方を工程にしたものです。本文と図は写していません。

- 空気の流れが形を決める。どこに空気を通し、どこで押さえ付けるかを先に決め、外形はその結果にする（空気の筋書き）。
- パッケージを詰める。車輪・乗員・機械を先に置き、外形はその包絡にする（硬い点とパッケージ）。
- 製図板で全体を描く。側面・平面・正面の線で全体を一度に考え、3次元の面は線から作る（3面の線図）。
- 規則を読む。寸法の枠と条件を先に書き、その中で最大限を狙う（性格と規則）。
- 全体を1人が見る。各工程の判断を1人で取り、部分の工程でも線図を基準に戻る（判断の記録）。
- 作って測って直す。指標と絵で確かめ、案→1案→修正の短い往復にする（比率・空力の簡易検査）。

## 項目と引用

| 項目 | ID | 置く成果物 |
|---|---|---|
| 性格 | TR-{nn} | 性格と規則 |
| 規則 | RL-{nn} | 性格と規則 |
| 比率の目安 | PT-{nn} | 性格と規則 |
| 硬い点 | HP-{nn} | 硬い点とパッケージ |
| 空気の筋 | FL-{nn} | 空気の筋書き |
| 案 | VA-{n} | 3面の線図 |
| 主な線 | LN-{nn} | 3面の線図 |
| 比率の測り | PM-{nn} | 比率 |
| 面 | SF-{nn} | 面 |
| 面の確かめ | SC-{nn} | 面 |
| 空力の所見 | AF-{nn} | 空力の簡易検査 |
| 細部 | DT-{nn} | 細部 |
| 配色 | CS-{n} | 色と材料 |
| 材料 | MA-{nn} | 色と材料 |
| 絵 | RD-{nn} | 最終の絵と動画 |
| 判断 | DC-{nn} | 判断の記録 |

主な引用は、**硬い点 → 規則、空気の筋 → 硬い点、主な線 → 案と根拠（硬い点・空気の筋・性格）、比率の測り → 目安と案、面 → 主な線、面の確かめ → 面、空力の所見 → 空気の筋、細部 → 主な線か空気の筋、材料 → 配色、絵 → 配色（必ず）、判断 → 決めた対象（性格・規則・硬い点・空気の筋から、案・測り・面・所見・細部・配色・絵まで、どの工程の項目でもよい）**です。

網羅では、すべての案・空力の所見・配色に判断があること、すべての目安に測りがあること、すべての硬い点が線か空気の筋に、すべての空気の筋が所見か細部に、すべての主な線が面か細部に使われていること、性格のことばが線か判断に表れていることを確かめます。規則・目安・硬い点・空気の筋・主な線・面の確かめ・性格は、理由を書けば `exempt` で除けます。

判断の記録は最後の工程の成果物ですが、判断は各工程の終わりに書き足していきます。

## 比率の目安の例

目安は車ごとに「性格と規則」で決め直します。次は2座のスポーツカーの初期値の例です。測定ではなく、形を決めるための目印です。

| 目安 | 初期値の例 |
|---|---|
| 車輪の外径 / 全高 | 0.5以上 |
| ホイールベース / 全長 | 0.58〜0.62 |
| 前のオーバーハング / ホイールベース | 小さいほど締まって見える |
| 窓の高さ / 車体の高さ | 0.4前後 |
| 全幅 / 全高 | 1.6以上 |
| タイヤの外面とフェンダーの差 | 0〜20 mm |
| タンブルホーム | 車の性格で決める |

## 評価と承認の境界

- AI は見出しと項目の抜け、引用と網羅の切れ、判断の無い案・所見・配色を指摘します。
- 人は案の選択、比率の骨格、面と細部の出来、配色、最終の絵を決めます。
- 空力の簡易検査は形の指標で、風洞や数値解析の代わりになりません。法規への適合も保証しません。
- 実在の車名・標章・意匠を写しません。参考にした考え方は出典と要約の範囲を「進め方」に書きます。

## 利用側が受け持つこと

- **製図板**：側面・平面・正面を同じ縮尺で並べ、硬い点を下絵にして線を描く道具。影絵の表示。
- **線から面**：2面の線から3次元の曲線を作り、曲線網で面を張る道具。曲率と映り込みの確かめ。
- **指標**：比率と空力の簡易な指標を、モデルから出す道具。
- **絵と動画**：写実の光の静止画、案の並べ比べ、回り込みと走行の動画の書き出し。

## 検証

`npm run check` が正式な必須検査です（schema の生成物の整合、定義の検査、契約試験）。定義の検査はデザインの出来を保証しません。
