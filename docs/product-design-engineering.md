# メカニカル製品の開発の定義

`product-design-engineering@1.0.0` は、腕時計や自動車のように機構と外装を持つ組立製品を、企画から設計・試作検証・調達・生産準備・量産と振り返りまで進める汎用定義です。特定の製品・道具・ファイルの形式を固定しません。既存の format 1 の schema を使用します。

**11工程・27成果物・36項目・57引用／網羅規則・40達成条件**。各工程には人が確認する達成条件があります。AI の達成条件は項目の引用・網羅、見出しと値の不足、3Dモデルでの干渉や寸法などの確かめに限り、意匠の良し悪しや、製品を出してよいかを自動判定しません。

## セクションと工程

| セクション | 工程 | 主な成果物 |
|---|---|---|
| 企画 | 進め方 → 製品企画 | 工程計画、企画書、要求一覧 |
| 設計 | コンセプト設計 → 基本設計 → 詳細設計 | コンセプト検討、ハードポイント、リスク一覧、アーキテクチャ、配置の3Dモデル、割付け、部品表（設計）、設計FMEA、工法と調達の方針、詳細の3Dモデル、図面、重要特性、解析報告、面品質と意匠の確認、製造性の確認 |
| 設計検証 | 試作・設計検証 | 設計検証の計画、設計検証の報告 |
| 調達と生産準備 | 調達・取引先開発 → 生産準備 → 量産試作・工程検証 | 見積と取引先、部品の承認、工程の流れ、管理の計画、工程検証の報告 |
| 量産 | 量産立上げ → 量産・振り返り | 立上げの記録、学びの記録 |

`after` は工程の**受け入れ順**です。調達と生産準備は詳細設計の受け入れの後に、試作・設計検証と並んで進められます。量産試作・工程検証は、設計検証・調達・生産準備の三つがそろってから受け入れます。

## 使い方と省略

対象の製品と出口を「進め方」に記します。電子・ソフトを含む製品では、それらの開発は別の定義に任せ、つなぎ目（インターフェース）だけをこの定義の部分として持ちます。

工程の深さは製品に合わせます。たとえば外装が主役の製品では外装の方向と面品質の確認を厚くし、機構が主役の製品では噛み合い・公差の積み上げ・寿命の解析を厚くします。途中の工程までで止める（たとえば詳細設計の出図までを受け入れる）ときは、後の工程の成果物を省いた理由と、網羅の規則から除く項目とその理由を記します。

人と AI が協働する場合、要求・方式の案・3Dモデル・解析・製造性の指摘のそれぞれで、AI が提案したものと人が決めたものを分けて記します。ゲートの判定と、直さない指摘の判断は人が行います。

## 3Dモデルと図面

- **配置の3Dモデル**（基本設計）：ハードポイントを名前の付いた寸法（配置の寸法）として持ち、部分ごとの空間を形（配置の形）として置きます。動く部分は動く範囲の空間で置き、互いにぶつからないことを確かめます。
- **詳細の3Dモデル**（詳細設計）：部品の形（部品の形）は部品表の部品を引用します。形を寸法で動かす部品は、部品の寸法を配置の寸法から引用します。部品ごとに分けても、一つにまとめても構いません。
- **形から寸法への引用**：配置の形は動かす配置の寸法を、部品の形は動かす部品の寸法（または配置の寸法）を引用できます。ハードポイントを変えたときに、どの形と、その形を引用する解析・外装の確認が影響を受けるかを、引用でたどれます。
- **図面**：形の正を3Dモデルとし、寸法・公差・材料と処理を表で足す形（製品製造情報）でも、2D の図面でも構いません。購入品と標準品は図面の代わりに仕様で決め、網羅の規則から理由つきで除きます。

引用は要求から下流へ向かって張ります。要求は使われ方・比べる製品・法規を、方式の案と外装の方向は要求を、配置の形は部分を、部品の形は部品を、解析は要求と3Dモデルの形を、重要特性は部品と根拠（要求か故障モード）を引用します。量産の側では、工程の作業が部品を、管理の項目が重要特性と作業を、工程能力が重要特性を、認証が法規を引用します。

網羅の規則（たとえば「すべての要求が解析か試験で確かめられている」「すべての部品に形がある」）はすべて理由つきで除けます。除いた項目は受け入れのときに人が理由を確かめます。

## 見本

`fixtures/product-design-engineering/` に、詳細設計の出図までを通した見本が二つあります。

- `skeleton-watch.json`：スケルトンの手巻き腕時計。部品ごとの詳細の3Dモデルで、可動部の干渉と歯車の噛み合いを確かめる。
- `mid-engine-car.json`：ミッドシップの2人乗り。外形の詳細設計だけを行い、骨格と足回りは部品表の行と除外の理由で残す。
