01WHY IT MATTERS

「やり方」を、
誰かの頭の中だけに置かない。

仕事は指示文だけでは進みません。順序があり、成果物があり、参照する情報があり、人が受け入れる条件がある。その構造を共通言語として扱います。

01 / PHASES

工程を定義する

何をどの順に行うか。工程ごとの目的、前後関係、必要な成果物を明示する。

02 / DELIVERABLES

成果物を定義する

文書、図、表、コード。何を残し、どんな項目を持たせるかを共有する。

03 / RELATIONSHIPS

つながりを定義する

どの情報が何を根拠としているか。引用と網羅の規則を明示する。

04 / ACCEPTANCE
✓

完了を定義する

誰が何を確かめるのか。機械で検査する条件と人が判断する条件を分ける。
