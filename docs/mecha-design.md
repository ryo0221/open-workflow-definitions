# アニメのメカデザインと玩具化の定義

`mecha-design@1.0.0` は、アニメに出す変形・合体のメカを、言葉で決めた企画（コンセプト・特徴・新しさ・要求）と合体の構想から決め、シルエットと比率、2次元の線図（三面図）と変形図で形と仕組みを固め、それを下敷きにした3Dモデルで成り立ちを確かめてから、設定画の決定稿・玩具化の検討・色彩・見せ場の絵と動画へ進める定義です。

**12工程・12成果物・20項目・41引用／網羅規則・25達成条件**。各工程に人が確かめる達成条件があります。AI の達成条件は、見出しと項目の抜け、引用と網羅に限ります。形の良し悪しと商品としての成否は、進め方で決めた人が決めます。

## セクションと工程

| セクション | 工程 | 主な成果物 |
|---|---|---|
| 企画 | 進め方 → 企画（コンセプトと要求） | 進め方、企画（コンセプトと要求） |
| 形 | 合体の構想 → シルエットと比率 → 線図（三面図） | 合体の構想、シルエットと比率、線図 |
| 仕組み | 変形と合体の仕組み → 3Dモデル | 変形と合体の仕組み、3Dモデル |
| 決定稿 | 設定画（決定稿）・玩具化の検討 → 色彩 | 設定画、玩具化の検討、色彩 |
| 見せ場と決定 | 見せ場 → 決定と記録 | 見せ場、判断の記録 |

`after` は工程の**受け入れ順**です。設定画と玩具化の検討は、3Dモデルの受け入れの後に並んで進み、色彩は二つがそろってから受け入れます。作画の色と玩具の色を同じ配色から決めるためです。

## 複数の組織で決める

この定義は、一つのメカに複数の組織の人が関わることを前提にしています。

- 制作の側：監督（作品の中での役割と見せ場）、ディレクター（話数・尺・予定）、メカデザイナー（形と仕組み）。
- 玩具の側：商品の担当（価格・対象年齢・売り場）、設計の担当（保持・強度・安全・費用）。

**進め方**で、工程ごとに呼ぶ人と、どの組織から何人の承認で受け入れるかを決めます。人の達成条件は「誰が何を確かめるか」を書き、承認の数え方（組織と人数）は使う道具の承認の条件で持ちます。議論で出た指摘は**判断の記録**の指摘（IS）に一件ずつ残し、対象の項目（参考を含む）を引きます。決定と記録の工程では、指摘がすべて判断（DC）に引かれていること（`issue-covered`）を確かめます。

## 考え方

- 形より先に言葉で決める。コンセプトを一文で書き、特徴と、これまでのメカに無い新しさを一件ずつ挙げる。新しさは何と比べたか（一般的な型で）と、どの特徴で実現するかを引く。
- 形より先に要求を並べる。監督の見せ場と玩具の商品の条件は、ぶつかることが多い。出した人の立場と優先の順を付けて、後の判断で引く。
- 合体は表と図で先に決める。何機が、どの順に、どの部位になるかを決めてから、シルエットを描く。
- 魅力と整合性を分けて決める。シルエット・比率・独創性などの魅力は、物理の正しさでは測れない。案を並べ、評価の観点（識別性・比率・統一感・独創性・世界観との合い方・ポーズの映え）ごとの所見を AI が書き、選ぶのは人が判断として決める。整合性（寸法・関節・干渉・変形）は部品の対応と動きの検証で確かめる。
- 遠目の影で役割を読ませる。シルエットの段階で細部を描かない。
- 参考は考え方を学ぶために使う。企画の参考（RF）に、何を学び何を写さないかを書く。資料は手元で見るだけで、素材として再配布しない。
- 骨格と外装を分ける。3D では関節のある骨格と、乗り物の外板・装甲を別の部品にし、外装の干渉も確かめる。外装の分割・マーキング・材質は設定画のディテールで決める。
- 3Dの前に2次元の線図を描く。形態ごとに正面・側面・上面を同じ縮尺で描き、案を並べて選ぶ。手順ごとの変形図も線図の上で描く。3Dモデルは線図を下敷きに組み、線図との違いを測る。
- 寸法で突き合わせる。機体のどの部分が合体の姿のどの部位になるかを部品の対応（PT）に一件ずつ挙げ、乗り物の形での寸法と、部位としての寸法を並べる。16 m の車両は 10 m の腰に入らない。絵だけでは見えないこの食い違いを、仕組みの工程で確かめる。
- 仕組みは手順ごとに確かめる。関節と結合点を一件ずつ挙げ、手順ごとに干渉・届くか・保持を確かめる。
- 変形は3Dで動かして確かめる。3Dモデルでは乗り物の形と合体の形を**同じ部品と関節**から組み、手順どおりに関節を動かす。動きの途中の干渉と届くかを、手順ごとに動きの検証（MV）に残す。形態ごとの静止した姿勢だけを確かめても、変形の途中の破綻は見えない。
- 絵は確かめた形から描く。設定画の絵を AI で生成するときは、3Dで動きを確かめた部品の対応と比率を下敷きにし、入力を書く。格好は良くても変形できない絵を決定稿にしない。
- AI の出したものは人が見て直す。3Dモデルの「手で直した所」に、AI の案から人が直した所と理由を残す。
- 既存の作品のメカ・名前・標章を写さない。

主な引用：参考は要求・特徴・新しさのどれかを、特徴は要求を、新しさは特徴を、シルエットの案と比率の測りは形態を（要求なども引ける）、線図は形態・シルエット・比率をそれぞれ一つ以上、機体は要求を、形態は機体を、部品の対応は機体と形態の両方を、手順は関節を一つ以上（形態や前の手順も引ける）、確認は手順・関節・部品の対応のどれかを、動きの検証は手順・関節・部品の対応をそれぞれ一つ以上、設定画は形態・シルエット・線図・動きの検証をそれぞれ一つ以上、玩具の確認は要求・関節・手順・形態のどれかを、配色は機体を（要求も引ける）、見せ場は形態か手順を（配色も引ける）引きます。判断は、受け入れるか退ける確認（CK）の結果や、比率の測り・参考も引けます。網羅：要求は機体・シルエット・比率・玩具の確認・配色・指摘・判断のどれかに引かれる（理由を書けば除ける）。手順は確認に、関節は確認か玩具の確認に（手順で使っただけでは足りない）、機体は部品の対応に、部品の対応は確認か動きの検証に、手順は動きの検証に、指摘は判断に、必ず引かれます。
