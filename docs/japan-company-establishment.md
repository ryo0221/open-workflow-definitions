# 日本の株式会社設立と事業開始の定義

`japan-company-establishment@1.0.0` は通常の発起設立を主な経路とする汎用定義です。法人名、所在地、資本金、出資者、開始日、採用する道具やファイルの場所はプロジェクト側で決めます。schema は既存の format 1 のままです。

まず進め方の図を確かめ、会社の存在意義・目指す未来、事業構想・顧客価値、製品と事業の戦略、組織・協業、会社紹介を人に伝わる図として制作します。その方針に基づき、法人設計→資金準備→登記を進めます。知財・権利の整理は進め方の確認後に始められます。登記後は税務・労務・銀行会計を並行して扱います。契約と業務基盤は事業構想・製品戦略・権利確認を踏まえて準備し、会社紹介とあわせて事業開始の判断と初回レビューへ進みます。after は受け入れ順であり、準備着手や法定期限の待機命令ではありません。特に雇用・報酬・課税などの起算事実が先行したら、工程表示に関係なく手続きを行います。

16工程・19成果物・34達成条件です。理念・事業・製品・組織・会社紹介の図も一つ一つを ID のある項目にし、法人設計・労務・業務基盤・事業開始の項目はそれらを引用できます。上流の考え方が変わったときの影響は、この引用をたどって出します。各工程には人が確認する条件があります。AI の条件に付けた cites は項目間の接続だけを検査します。行の存在、引用の成立、工程の受け入れは、登記・納税・権利承継・契約締結の実行を意味しません。

成果物は、理念・事業・組織・会社紹介と進め方を示す図と、実務を管理する表の台帳に分かれます。台帳の管理項目の共通欄は定義の outline に記載します。実際の項目、引用の外部表、期限の日付、証跡、権限、担当は利用側で管理します。対象外にするときは適用判断の理由・確認者・再確認条件を記録します。定義の工程自体を省く場合も理由が必要です。未確認を対象外で代用しません。

通常の発起設立以外、現物出資、外国居住者・外国出資、規制業種、設立前の契約、既存事業・資産の移管は追加確認が必要です。定義がこれらの適法性を保証するものではありません。専門家への相談が必要な具体的論点をプロジェクトの未確認事項として残します。

国税庁 [新設法人の届出](https://www.nta.go.jp/taxes/shiraberu/taxanswer/hojin/5100.htm)、法務局 [設立登記の添付書面](https://houmukyoku.moj.go.jp/homu/shogyo_online01_01.html)、日本年金機構 [新規適用](https://www.nenkin.go.jp/shinsei/kounen/tekiyo/jigyosho/20141205.html) を入口に、最新の一次情報と所在地の自治体資料をプロジェクト側で確認します。一般的な日数をそのまま会社の期限に変換せず、起算事実・適用条件・休日の取扱い・提出先を確認して期限を確定します。

秘匿原本はアクセスを制限した別保管先で管理し、公開しうる台帳には原本・個人番号・口座・認証情報・契約条件・未公開発明を書きません。公開する場合は明示的に選んだ成果物だけを確認します。

検査: `node scripts/check.mjs`。これは定義の形と参照の検査です。会社設立の実務完了は検査しません。リリース時は既存方針に従って版のタグを管理します。本変更だけでタグを発行・公開したとは扱いません。

## 工程のセクション

| セクション | 工程 |
|---|---|
| 会社の理念と事業像 | 進め方、会社の存在意義・目指す未来、事業構想・顧客価値、事業とプロダクトの戦略、組織・協業の設計、会社紹介・対外発信素材 |
| 会社を形にする | 法人の基本設計、設立資金と出資、知財・権利承継、定款・払込み・設立登記 |
| 事業を動かす準備 | 税務・自治体の届出、社会保険・労務、銀行・会計・資金繰り、契約・情報管理・業務基盤 |
| 公開と継続運営 | 事業開始の判断、初回運営レビューと継続管理 |

定義の sections は既定のまとまりです。各工程は一つのセクションに所属し、セクション内外の並びは after の依存順と整合します。セクションは全工程を直列化するゲートではありません。登記後の税務・社保等はそれぞれの起算事実から進めます。
